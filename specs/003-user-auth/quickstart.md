# Quickstart: Autenticação

Para configurar a nova funcionalidade de autenticação:

1. Executar migrações do Prisma para adicionar a entidade `User` no banco de dados.
2. Implementar middleware de validação JWT no backend.
3. Criar `AuthProvider` no frontend para envolver a aplicação.
4. Proteger rotas usando o hook de autenticação.
